# Second implementation

The first level and the second level of the paper are computed by `tfilter` and `tdeep` (Rust, `code/impl1/rust/`). This directory holds a second implementation of both levels, `vlevel1` and `vkill` (Rust, crate `tverify`; Section 9.3 of the paper). It was written from a written description of the arguments of Sections 4 to 6 and from the data files, without reading the source of the first. It writes no certificates: its verdicts are checked by rerunning it.

|                      | first implementation (`code/impl1/rust`)                                                                                                                                   | second implementation (this directory)                                                                                                                                                  |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| interval arithmetic  | IEEE 754 binary64, each operation widened by one ulp (`iv.rs`, `ivt.rs`)                                                                                                   | its own, the same model (`iv.rs`)                                                                                                                                                       |
| elementary functions | Cody and Waite reduction by `π/2` in three parts, Taylor polynomials of degree 20 and 21, `arctan` from a table of `arctan(j/8)` (`rtrig.rs`); MPFR as an optional backend | tables of `cos(k/64)`, `sin(k/64)`, `arctan(k/64)` enclosed with MPFR, Taylor polynomials with Lagrange remainders (`elem.rs`, `mp.rs`)                                                 |
| contractors          | the relations of Section 6.2, natural interval extensions                                                                                                                  | mean value forms by automatic differentiation (`ad.rs`), more relation families per face: every triple of other corners of a hexagon, pentagon splittings along a diagonal (`faces.rs`) |
| gluing, Pair, Local  | `local.rs`                                                                                                                                                                 | its own (`glue.rs`)                                                                                                                                                                     |
| further refutation   |                                                                                                                                                                            | Edge: the enclosure of each edge length against `2 sin(d/2)`                                                                                                                            |
| first level          | `tfilter`: the rows of Section 6.1                                                                                                                                         | `vlevel1`: the same rows and the rows "the corners of an `m`-gon sum to at least `(m - 2)π`" (`level1.rs`)                                                                              |
| output               | a search tree per graph, replayed by `tdeep --replayfile`                                                                                                                  | a verdict line per graph                                                                                                                                                                |

The constants of `src/consts.rs` are checked by `consts_check.gp` (PARI/GP, 200 digits; output `consts_check.out`; rerun by the job `gp` of the continuous integration).

## Rerunning

```
code/rerun.sh build_impl2 test_impl2 sample_kill
JOBS=4 code/rerun.sh residue_a residue_b residue_c residue_d residue_e
```

The bulk passes need the level-2 input files of the release assets (`code/impl1/fetch_assets.sh`): `vkill ASSETS/inputs/in_k0_0.pc --iso 0 --targets data/tie_targets.txt --local --pair --edge --nodes 30000 --maxsec 5`, and so on for each input file. They are not rerun by the continuous integration (about 14 core hours).

## Relations against the relation system of D3

The paper (Section 9.3) says that the second program uses more relations per face than the relation system `RelSys` of D3 (`Tammes15/Hyps/Case.lean`). The tables below compare each relation and each test of the programs of this directory with `RelSys`; line numbers are those of the sources of this directory.

vlevel1 (src/level1.rs, stage A):

| row                                                                                        | where       | status                                                                 |
| ------------------------------------------------------------------------------------------ | ----------- | ---------------------------------------------------------------------- |
| a in [alpha(dlo), alpha(dhi)], triangle corners = a                                        | l.44        | `tri` with `alpha` increasing (row (1), `alpha_strictMonoOn`)          |
| rhombus x, y in [a, 2a], x + y >= 3a, x + y \<= S(dhi)                                     | l.61 to 72  | `rhombus` with `corner_mem` (row (2), `rhombus_rows` of Trigrows)      |
| pentagon and hexagon corners in [a, pi]                                                    | l.78, 80    | `corner_mem` (row (3))                                                 |
| vertex sums = 2 pi                                                                         | l.92 to 106 | `vertex_sum` (row (4))                                                 |
| **Girard rows**: corners of a pentagon sum to at least 3 pi, of a hexagon to at least 4 pi | l.83 to 86  | **outside `RelSys`**; on by default, off with `--noarea` or `--relsys` |

The three families hold for a convex equilateral polygon, but they follow from `pent`, `hex` and `hexDiag` only through a realisability lemma of the face (a solution of the `RelSys` relations of a face is the corner tuple of a convex polygon), which is stated nowhere. They are listed in `OUTSIDE_RELSYS` (src/model.rs).

The rest of the search (mean value forms, monotonicity, Newton steps, 3B shaving, `--lp`) are contractions of the same relations; with fewer relations they contract less, never more.
